# 통장 자동 분개 (journal_automation)

거래처 통장 거래내역을 넣으면 세금계산서·급여대장·사업소득·예수금(원천세, 4대보험)을 대조해
일반전표를 만들고, 개인 이름으로 들어온 입출금은 **거래처 원장의 대표자명**으로 회사를 찾아 거래처로 지정합니다.

## 거래처 폴더로 쓰기 (권장)

```bash
pip install -r requirements.txt
python client.py new   가나상사                 # input/가나상사/ 를 자료 틀로 생성
python client.py add   가나상사 받은파일들...     # 파일 내용을 보고 번호 폴더로 자동 분류
python client.py check 가나상사                 # 빠진 자료·주의사항
python client.py run   가나상사                 # input/가나상사/결과/ 에 검토용 + 세무사랑 업로드 파일
```

어떤 자료를 어느 폴더에 넣는지는 [`client_template/자료안내.md`](client_template/자료안내.md),
각 폴더의 `안내.txt` 참고. `작업정보.json` 에 시작일(이미 작업한 날 다음 날)·종료일, `고객설정.json` 에 거래처 전용 규칙.

## 직접 실행

```bash
pip install -r requirements.txt
python auto_journal.py \
  --bank 통장.xlsx \
  --ledger 거래처원장.xlsx \
  --sales 매출세금계산서.xlsx \
  --purchase 매입세금계산서.xlsx \
  --payroll 급여대장_8월.xlsx 급여대장_9월.xlsx \
  --business 사업소득.xlsx \
  --withholding 예수금원장.xlsx \
  --owner 김대표 \
  --company "(주)거래처명" --company-bizno 123-81-00001 \
  --out 분개결과.xlsx
```

결과물 두 개가 나옵니다.

- `분개결과.xlsx` — 검토용 (확인필요·거래처매칭·중복인원 등, 노란색 표시)
- `분개결과_세무사랑업로드.xls` — **세무사랑 「엑셀자료 일반전표전송 v1.2」 양식**에 통장 전표를 채운 파일.
  세무사랑에서 바로 업로드. (체크카드 제외, 확인필요 행은 노란색)

`--bank` 외에는 모두 선택입니다. 자료가 많을수록 자동 분개 비율이 올라갑니다.
`samples/` 폴더에 가상 자료와 결과 예시(`분개결과_예시.xlsx`)가 있습니다.

## 넣는 자료 (머리글 행은 자동 탐색, 위쪽 제목행 있어도 됨)

| 자료 | 인식하는 열 이름(예) |
|---|---|
| 통장 | 거래일자/거래일시, 입금액/맡기신금액, 출금액/찾으신금액, 적요·기재내용·받는분/보낸분 (또는 금액+입출금구분) |
| 거래처 원장 | 거래처코드, 거래처명, 사업자등록번호, 대표자명, (선택) 계정과목, (선택) 통장표시명 |
| 세금계산서 | 홈택스 「목록조회」 엑셀 그대로 (공급자/공급받는자 상호·대표자명 자동 구분). 간단 양식(작성일자·거래처·공급가액·세액)도 가능 |
| 급여대장 | 귀속월, 성명, 지급총액, 소득세, 지방소득세, 국민연금, 건강보험, 장기요양, 고용보험, 공제총액, 차인지급액 |
| 사업소득 | 귀속월, 성명, 지급액, 소득세, 지방소득세, 차인지급액 (세액 열이 없으면 3%/0.3% 계산) |
| 예수금 원장 | 더존 거래처원장/계정별원장(예수금): 일자(`01-31`처럼 연도 없어도 됨), 적요, 거래처, 차변, 대변. 대변(예수 발생)만 귀속월별로 집계, 전기이월·월계·누계 행 제외. 거래처·적요로 건강/연금/고용/소득세/지방소득세 구분 |

## 분개 순서 (위에서 먼저 맞으면 확정)

> **체크카드 제외**: 통장 행 어느 칸이든 `체크`가 들어 있으면 세무사랑에서 따로 처리하므로 전표를 만들지 않고
> `제외(체크카드)` 시트에만 남깁니다. (`config.json` 의 `exclude_keywords`)

**출금**
> 급여·사업소득·매입대금 출금은 금액이 그대로 맞는지 먼저 보고, 안 맞으면 **고정 송금수수료(기본 500원)만** 빼고
> 다시 맞춰 봅니다. 맞으면 500원은 지급수수료(831)로 분리. 500원이 아닌 차액은 수수료로 보지 않고 확인필요로 남깁니다.

1. 급여대장: 이름 + 실지급액 일치(또는 월 합계 일괄이체) → **미지급비용 / 보통예금** (미지급비용 털어내기)
2. 사업소득: 이름 + 차인지급액 일치 → **미지급비용 / 보통예금**
   - 급여·예수금·미지급비용 발생 전표는 급여대장으로 이미 잡혀 있다고 보고, 통장에서는 미지급비용만 정리
   - 500원 차이 → 지급수수료(831). 그 외 차액: 더 나가면 가지급금, 덜 나가면 미지급비용 잔액 남김 (확인필요)
3. 원천세·지방소득세 납부 → 예수금 / 보통예금 (직전월 예수액과 대조, 다르면 확인필요)
4. 4대보험 → 차변 예수금(**직전월 예수금**) + 차변 회사부담 비용(납부액 − 예수금) / 대변 보통예금

   | 보험 | 예수금 차감 | 나머지(회사부담) |
   |---|---|---|
   | 건강보험(장기요양 포함) | O | 821 보험료 |
   | 고용보험 (고용산재 통합 납부 포함) | O | 821 보험료 |
   | 국민연금 | O | 817 세금과공과 |
   | 산재보험 | X | 출금액 전액 821 보험료 |

   - 직전월 예수금: 예수금 원장 우선, 없으면 급여대장 공제액. 같은 달 예수금은 한 번만 차감
   - 통장에 `근로복지공단`만 찍혀 고용/산재 구분이 안 되면 고용보험으로 처리하고 확인필요
   - 예: 2/10 건강보험 1,000,000 출금, 1월 예수금 500,000 → 예수금 500,000 + 보험료 500,000 / 보통예금 1,000,000
5. 대표자 본인(`--owner`) → 가지급금(법인) / 인출금(개인)
6. 매입 세금계산서: 거래처 인식 + 금액 일치(단건 또는 여러 건 합계) → 외상매입금 / 보통예금
7. 키워드 규칙(config.json) → 통신비·수도광열비·카드대금(미지급금)·이자비용 등
8. 거래처 원장에만 있는 업체 → 외상매입금 (확인필요)
9. 거래처 연결 안 됨 → **외상매입금** (확인필요, 노란색)

**입금**: 대표자 → 매출 세금계산서 → 키워드 규칙 → 원장 업체 → 거래처 연결 안 되면 **외상매출금**(확인필요, 노란색)

**급여·사업소득 양쪽에 있는 사람**: 지급 분개는 그대로 하되 노란색 + 확인필요로 표시하고,
`급여·사업소득중복` 시트에 그 사람의 급여·사업소득 내역을 모아 보여줍니다.

## 거래처 인식

- **상호일치**: `(주)`, `주식회사` 등을 떼고 비교. 통장에 잘린 이름(`(주)한빛상`)도 인식
- **별칭일치**: 거래처 원장의 `통장표시명` 열 (예: 케이티 → `KT`)
- **대표자명일치**: 통장에 개인 이름만 찍힌 경우 원장(또는 세금계산서)의 대표자명으로 회사를 찾음.
  동명 대표가 여러 회사면 세금계산서 금액이 맞는 회사를 고르고, 그래도 여럿이면 확인필요
- 세금계산서에는 있는데 원장에 없는 업체는 **신규거래처등록** 시트에 사업자번호·대표자와 함께 정리

## 결과 엑셀 시트

| 시트 | 내용 |
|---|---|
| 요약 | 건수, 입출금 합계, 인식방법별 건수 |
| 일반전표(통장) | 월·일·전표번호·구분(3차변/4대변)·계정코드·거래처코드 — 검토용. 노란색 = 확인필요 |
| 매입매출전표(세금계산서) | 세금계산서별 매출(11.과세/13.면세)·매입(51/53) 분개 |
| 거래처매칭 | 통장 각 행이 어느 거래처로, 어떤 근거로 연결됐는지 |
| 확인필요 | 사람이 봐야 할 거래와 사유 |
| 제외(체크카드) | 전표에서 뺀 체크카드 거래 (대조용) |
| 급여·사업소득중복 | 급여대장과 사업소득 내역 양쪽에 있는 사람 (노란색) |
| 신규거래처등록 | 원장에 등록해야 할 업체 |
| 미결세금계산서 | 통장과 연결 안 된 세금계산서(미수·미지급 잔액 점검용) |

## 설정 (config.json)

- `accounts`: 계정과목 ↔ 코드 (세무사랑 계정코드 — 사무실 코드에 맞게 수정)
- `entity_type`: `법인` / `개인`
- `officer_names`: 임원 이름 → 임원급여로 처리
- `rules`: 통장 키워드 → 계정. 거래처마다 반복되는 자동이체는 여기에 추가
- `transfer_fee`, `transfer_fee_account`: 급여·사업소득·매입대금 송금 시 함께 빠지는 고정 수수료(기본 500원 → 지급수수료)
- 회사부담 4대보험 계정, 미확인 입출금 계정 등

## 주의

- 매입매출전표 시트와 일반전표의 외상매출금/외상매입금은 짝을 이룹니다. 매입매출을 더존에 따로 입력한다면 일반전표만 쓰면 됩니다.
- 실제 거래처 자료(통장, 급여대장 등)는 이 저장소에 커밋하지 마세요. `.gitignore`가 `input/`, `output/` 폴더와 샘플 외 엑셀을 막아 둡니다.
