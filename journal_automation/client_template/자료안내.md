# 거래처 통장 분개 — 준비 자료 체크리스트

거래처마다 이 폴더를 복사해 쓴다 (`python client.py new <거래처명>`).
자료를 각 번호 폴더에 넣고 `python client.py check <거래처명>` 으로 빠진 것을 확인한 뒤
`python client.py run <거래처명>` 으로 분개한다. 결과는 `결과/` 폴더에 생긴다.

| 폴더 | 자료 | 필요도 | 세무사랑 메뉴/받는 곳 |
|---|---|---|---|
| 01_통장 | 통장 거래내역 엑셀 | **필수** | 은행 인터넷뱅킹 |
| 02_일반거래처 | 일반거래처 등록 LIST | 권장 | 세무사랑 거래처등록 → 출력(엑셀) |
| 03_금융거래처 | 금융기관거래처 등록 LIST | 권장 | 세무사랑 거래처등록(금융) → 출력(엑셀) |
| 04_매출 | 매입매출장(매출) | 있으면 | 세무사랑 매입매출장 → 엑셀 |
| 05_매입 | 매입매출장(매입) | 권장 | 세무사랑 매입매출장 → 엑셀 |
| 06_급여대장 | 급상여대장 (월별) | 있으면 | 세무사랑 급상여대장 → 엑셀 |
| 07_사업소득 | 사업소득 지급내역 | 있으면 | 세무사랑 사업소득 → 엑셀 |
| 08_예수금원장 | 거래처원장(254 예수금) | 있으면 | 세무사랑 거래처원장 → 엑셀 |
| 09_세금납부 | 국세 납부내역증명, 지방세 증명 | 있으면 | 홈택스·플랫폼세무사회·위택스 |

`작업정보.json` 에 회사명·사업자번호·시작일(이미 작업한 날 다음 날)·종료일을 적는다.

## 적용되는 사무실 원칙 (요약)
- 체크카드 거래는 전표에서 제외 (세무사랑에서 따로 처리)
- 송금수수료 500원 → 831 지급수수료
- 급여·사업소득 지급 → 미지급비용 털기 / 양쪽에 있는 사람은 노란색
- 4대보험: 직전월 예수금 차감, 나머지 건강·고용 821 보험료, 국민연금 817 세금과공과, 산재 전액 821
- 세무서 입금 → 미수금 / 보냈다가 돌려받은 계약금 → 예수금
- 세금: 근로·사업소득세 → 예수금, 법인세·법인지방소득세·부가세 → 261 미지급세금, 가산세 차액 → 930 잡손실
- 거래처 연결이 명확하지 않으면 억지로 연결하지 않고 코드 공란 → 출금 외상매입금 / 입금 외상매출금 (노란색)
- 애매한 계정은 확정하지 않고 노란색 — 사용자가 확인 후 연결
